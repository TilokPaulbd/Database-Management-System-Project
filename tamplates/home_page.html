About our project

The DIU Smart Transport System is an intelligent, web-based platform designed to modernize and simplify university transportation management. It allows students to easily book bus seats, view schedules, and track availability in real time. The system ensures efficient seat allocation, reduces manual workload, and enhances user convenience through a clean interface.

This project, developed for our Database Management System course, demonstrates the use of database integration and automation to improve transport management.
